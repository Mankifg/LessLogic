# LessGame
version: 1.0.4 



## What is this?
lessgame is a python package for handling game logic and game creation for game [Less](https://www.less-game.com/).

## Usage 
Generate new board: 
```python
from lessgame import gamegen
print(gamegen.game_numbers())
# [80, 36, 320, 9, 160, 1, 584, 11, 584]
```
